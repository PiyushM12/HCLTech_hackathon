# AI-usage disclosure

The guide allows and encourages AI coding assistants, provided their use is disclosed and every member can
explain the code. This is what was generated with AI and how it was checked.

## What was generated with an AI assistant (Claude, via Claude Code)

| Part | Generated | How it was verified |
|---|---|---|
| Backend code (`backend/app/**`, `scripts/**`) | Drafted by the assistant from the participant guide, then iterated on test failures | 38 pytest tests (`backend/tests/`); end-to-end smoke runs of every example request in guide section 2.1; the evaluation in `backend/eval/` |
| Frontend (`frontend/**`) | Drafted by the assistant | `npm run build` (strict TypeScript); a headless-Chrome run of every flow against the real API at desktop and 360 px mobile widths, with screenshots and a console-error check |
| Knowledge base (`backend/data/kb/**`), Source Register | Generated with the prompt in `data/prompts/kb_generation_prompt_v2.md` | A script checked that every rule and policy citation resolves to a real `## N` section and that the register matches the files; circular effects parsed by code were inspected by hand |
| Hindi, Kannada and Tamil text (documents, reply templates in `app/i18n.py`) | Generated by the assistant | Script check in the eval and cross-language number/verdict consistency. **Native-speaker review is still required** (log it in `docs/data_card.md`) |
| Citizen profiles | 25 base profiles generated with `data/prompts/citizen_generation_prompt_v1.md`; the 13 edge cases are written by code | Pydantic schema in the generator; `scripts/validate_data.py` (0 violations) |
| Evaluation sets | Drafted with the assistant, labels reviewed by the team | Labels are checked against the rule tables; the critic set's good/bad labels need a second human pass |

## No AI at runtime except the local model
At runtime, SchemeSathi calls only a local Ollama model, and only for classification and free-text answers.
It does not call any cloud LLM or translation service. `MOCK_LLM=true` runs the whole system without a model.
